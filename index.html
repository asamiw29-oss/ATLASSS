お店を追加

Google Maps で「共有 → リンクをコピー」→ ここをタップ
    ● 未設定 — 地図タップ / 現在地 / 検索 / GMapリンク

      設定 / 共同編集

      未設定：この端末にのみ保存されます
      シートを「リンクを知る全員が閲覧可」にしておく。シート名は stores。
      追加の書き込み先。アクセス「全員」でデプロイした URL。
      ▸ セットアップ手順（初回だけ）
      1. Google スプレッドシートを新規作成。シート名を stores にし、1行目に下のヘッダーを貼る。
        id,name,category,region,lat,lng,memo,address,registrant,role,delivery,created_at,place_id
      2. 共有 → 「リンクを知る全員」→ 閲覧者。URLの /d/ と /edit の間がシートID。
      3. 拡張機能 → Apps Script。下のコードを貼って保存。
      4. デプロイ → 新しいデプロイ → 種類「ウェブアプリ」→ 実行「自分」→ アクセス「全員」→ デプロイ。表示された …/exec URL をコピー。
      5. 上の2欄（シートID・Apps Script URL）に貼って「保存する」。以後、追加はみんなのシートに書き込まれ、全員に共有されます。
      読み取りは公開シートCSVから直接（無料）。書き込みは Apps Script 経由（無料）。Google Places は使わない構成なので API キー・課金・カード登録は一切不要です。
